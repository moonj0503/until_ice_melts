# 얼음이 녹을 때까지

사실적인 3D 얼음이 녹는 동안 공부하는 한국어 집중 타이머. ‘고요한 밤’ 디자인을 바탕으로 장식을 줄이고 얼음과 공부 시간에 집중하도록 구성했습니다.

## 실행

Node.js 22.18 이상이 필요합니다. 개발·검증 환경은 Node.js 24입니다.

```sh
npm ci
npm run dev
```

터미널에 표시된 로컬 주소를 브라우저에서 엽니다. 개발 서버는 기본적으로 이 기기의 루프백 주소에서만 실행됩니다.

```sh
npm test
npm run build
npm run preview
```

`npm run build`는 TypeScript 검사 후 `dist/`에 정적 사이트를 생성합니다. `dist/`를 정적 호스팅으로 배포할 수 있습니다. API 키나 백엔드는 필요하지 않습니다.

## 기능

- 시간 지정: 기본 50분, 1~720분의 정수 입력.
- 랜덤 챌린지: 얼음 크기와 주변 온도로 녹는 시간을 정합니다. 큰 얼음·낮은 온도일수록 오래 걸리며, 같은 조건에도 작은 무작위 편차가 있습니다. 시작 전 예상 시간과 진행 중 총시간·남은 시간은 표시하지 않습니다.
- 챌린지 설정: 슬라이더로 한 변 2~5cm(0.5cm 단위), 주변 10~35°C(1°C 단위)를 조절합니다. 기본값은 3cm·22°C이며 현재 값이 바로 표시됩니다. 설정한 크기는 화면의 얼음에도 반영합니다.
- 일시정지·재개: 휴식 시간은 제외하고 얼음 변화도 멈춥니다.
- 다른 탭·브라우저 종료 후에도 실제 경과 시간으로 이어집니다.
- 재접속 시 종료 시간이 지났다면 목표 시간으로 완료 처리하며 기록은 한 번만 저장합니다.
- 완료·중도 종료 기록, 총 공부 시간, 완료한 얼음 수를 확인합니다.
- 선택형 완료 알림음. 기본 꺼짐이며 브라우저 정책으로 소리를 낼 수 없을 때도 화면과 기록은 처리합니다.
- 세션마다 달라지는 비대칭 물 웅덩이, 실제 얼음의 수면 반사와 얇은 물 가장자리. 같은 세션을 복원하면 같은 윤곽을 유지합니다.
- PC·모바일 지원, 키보드 조작, 기록 대화상자, 3D 미지원 대체 화면.

## 저장과 복원

`localStorage`의 `until-ice-melts:v1` 키에 세션·기록·설정을 하나의 상태로 저장합니다. 브라우저 데이터를 삭제하면 기록도 사라집니다. 다른 기기나 브라우저와 동기화하지 않습니다.

저장소를 사용할 수 없는 경우 안내를 표시하고 메모리에서 타이머를 계속 실행합니다. 이 경우 새로고침·재접속 후 복원은 보장하지 않습니다. 손상된 데이터는 신뢰하지 않고 새 상태로 시작합니다.

브라우저가 닫혀 있는 동안에는 알림음을 재생할 수 없습니다. 다시 열면 완료 여부와 기록을 복원합니다. 기기의 시계를 수동으로 바꾸면 실제 시각을 기반으로 하는 타이머에 영향을 줄 수 있습니다.

## 구조와 기술 선택

- TypeScript + [Vite](https://vite.dev/guide/): 정적 빌드와 개발 서버. 작은 단일 화면에 UI 프레임워크를 추가하지 않았습니다.
- [Three.js](https://threejs.org/docs/): 투과·굴절 재질, 로컬 스튜디오 조명, 진행도 기반 얼음 형태와 물 표현. 외부 모델·HDR·이미지를 다운로드하지 않습니다.
- 브라우저 Web Audio API: 사용자의 동작에서 활성화되는 완료 알림음.
- Node.js 내장 테스트 + Playwright: 시간·저장·형상 로직과 실제 브라우저 흐름 검증.

`src/session.ts`는 시간·상태 계산, `src/storage.ts`는 데이터 검증과 복원, `src/ice-geometry.ts`와 `src/scene.ts`는 3D 표현, `src/main.ts`는 화면·조작 연결을 담당합니다. 3D는 별도 청크로 지연 로딩하며 타이머와 독립적으로 동작합니다.

`src/puddle-geometry.ts`는 세션 ID 기반의 절차적 물 윤곽과 가장자리 형상을 생성하고, `src/water.ts`는 수면 반사·프레넬·미세 요철을 표현합니다. 반사는 진행도 변화나 화면 크기 변경 때 갱신하며 별도의 상시 애니메이션 루프를 추가하지 않습니다.

정확한 의존성 버전은 `package-lock.json`에 고정되어 있습니다.

## 브라우저 테스트

```sh
npx playwright install chromium
npm run test:e2e
```

데스크톱과 모바일 크기의 Chromium에서 전체 흐름을 검증합니다. 모바일 테스트는 iPhone 크기·터치 환경을 에뮬레이션하며 실제 iOS Safari 검증은 아닙니다. 테스트는 5173 포트의 개발 서버를 자동 실행합니다.

검증 시나리오: 시간 지정, 크기·온도 입력 오류, 조건과 계산된 시간 유지·비공개, 이전 최소·최대 시간 설정의 마이그레이션, 여러 번 일시정지·재개, 새로고침, 창을 닫은 뒤 만료 복원, 중복 기록 방지, 저장소·WebGL 차단, 알림음 실패, 320px 배치, 기록 대화상자 닫기.

챌린지 시간은 실제 물리 실험을 예측하는 수치가 아니라 공부용으로 보정한 시뮬레이션입니다. 크기·온도에 따른 관계와 작은 무작위 편차를 적용하며, 한 번 결정한 시간은 재접속해도 다시 추첨하지 않습니다. 기존 방식으로 진행 중이던 세션과 공부 기록도 보존합니다.
